# Trust Trash Web

Next.js App Router starter. The UI currently contains a static product shell; it does not call the backend yet.

Feature folders are organized in four layers:
- `presentation`: components and views
- `application`: frontend use cases and state orchestration
- `domain`: framework-independent frontend models and validation
- `infrastructure`: API clients and transport mapping

Start with `npm install` and `npm run dev`. The search form is intentionally disabled until the Search API contract and permissions flow are implemented.
