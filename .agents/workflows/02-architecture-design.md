# 02 Architecture Design

## Purpose
Design a change within the Trust Trash layered modular architecture.

## Steps
1. Inspect current code, root/nested instructions, docs and ADRs.
2. Identify domain owner, current data flow and dependency direction.
3. Define API/resource/event/data contracts and error semantics.
4. Design sequence, component and deployment impacts.
5. Threat-model permissions, credentials, tenant boundaries and derived data.
6. Compare alternatives and record consequential choice in ADR.
7. Define tests, observability and rollback/migration strategy.

## Completion report
Updated architecture docs/ADR, contracts, module map and implementation plan.
