# 08 Website Feature

## Purpose
Deliver a Trust Trash web feature from user flow through production-quality UI.

## Steps
1. Read website and nested AGENTS; inspect installed Next/React version and existing patterns.
2. Write page/feature brief, route ownership and state inventory.
3. Define typed API contract, permission scope and server/client boundary.
4. Build components using design tokens and accessible semantics.
5. Implement loading, empty, partial, stale, forbidden and error states.
6. Add responsive, keyboard and screen reader checks.
7. Add component/integration/E2E tests and measure performance.
8. Run typecheck, lint, tests, build and update docs.

## Completion report
Complete interactive page/feature with acceptance and quality evidence.
