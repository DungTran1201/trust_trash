# 07 Processor Plugin

## Purpose
Add a processor for structured/document/multimodal data.

## Steps
1. Define manifest, input/output schema, resource limits and versioning.
2. Create representative golden dataset and baseline metrics.
3. Implement isolated processing without mutating raw content.
4. Validate output, provenance and evidence offsets.
5. Persist derived artifacts and publish events for indexing.
6. Add quality, resource, retry, privacy and security tests.
7. Document supported formats, language, limitations and model dependencies.

## Completion report
Versioned processor plugin, manifest, benchmark, tests and lineage evidence.
