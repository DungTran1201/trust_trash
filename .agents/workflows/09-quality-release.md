# 09 Quality Release

## Purpose
Verify a cross-domain change and prepare a safe release.

## Steps
1. Trace acceptance criteria to implementation and tests.
2. Run unit, contract, integration and E2E suites appropriate to risk.
3. Run security, accessibility, performance and data quality checks.
4. Verify migrations, backfills, idempotency and rollback/disable plan.
5. Review telemetry dashboards, alerts and runbooks.
6. Update docs, API/event contracts and release notes.
7. Report pass/fail/skipped checks without overstating results.

## Completion report
Release decision, evidence, known issues, rollout and rollback instructions.
