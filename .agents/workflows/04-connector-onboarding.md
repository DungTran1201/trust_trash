# 04 Connector Onboarding

## Purpose
Add a new data source from provider research to operational onboarding.

## Steps
1. Verify provider docs, scopes, quotas, API version and terms.
2. Define resource hierarchy, identity, capabilities and connector manifest.
3. Implement secret-safe auth and least-privilege config.
4. Implement health, discover, metadata, search/fetch/sync only where supported.
5. Implement pagination, checkpoint, retry, rate limit and ACL mapping.
6. Add contract fixtures, failure tests and metrics.
7. Run bounded integration and document setup, limitations and recovery.

## Completion report
Versioned connector with manifest, docs, tests, permission behavior and health status.
