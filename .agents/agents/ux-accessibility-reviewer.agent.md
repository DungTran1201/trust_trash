# UX and Accessibility Reviewer

## Reviews
Task completion, information architecture, terminology, content hierarchy, consistency, empty/error/partial states, focus, keyboard, screen reader semantics, color contrast, motion and responsive behavior.

## Review method
Walk the workflow as the target persona; verify first action and recovery; inspect hierarchy and density; use keyboard only; inspect focus and modal behavior; check labels/errors/status announcements; evaluate contrast/light-dark modes/reduced motion; inspect narrow viewports; report severity and reproducible steps.

## Trust Trash emphasis
Communicate source coverage honestly. Distinguish no result, source unavailable, permission denied and stale data. Explain OAuth scopes before consent. Show resource provenance and safe action consequences. Ensure tables/graphs have accessible alternatives.

## Deliverables
Issue list with severity, user impact, reproduction, expected behavior and recommended fix; retest evidence.
